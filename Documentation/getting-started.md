# Getting Started

## 1) Invite the bot

Invite the bot to your Discord server using the link provided in the project README.

## 2) First-time setup (Admins)

- Run `/setup_dkp`.
- The bot will create the DKP category/channels and the required roles.

## 3) Roles (what they mean)

- **Raider**: typical member participating in raids.
- **Officer**: can run officer actions (raid controls, awarding/deducting DKP).
- **Raid-Leader**: assigned for the duration of an active raid.

## 4) For players

- Use `/my_dkp` to see your current DKP.
- If your guild uses auctions, use `/auction_help` to learn the bidding flow.

## 5) For raid leaders / officers

- Use `/raid_create` to start a raid.
- Use the raid control panel in the raid thread to manage raid actions.
- Use `/award` and `/deduct` to adjust DKP (target a member, or leave blank to affect everyone in the raid voice channel).
- Use `/raid_end` to close the raid.

## 6) Common troubleshooting

- If commands don’t appear right away, wait a few minutes (Discord command sync can be delayed).
- If you can’t run an officer/admin command, confirm your role and server permissions.
