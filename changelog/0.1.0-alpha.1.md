## Change Log viewer

- Added a **Change Log 🔒** button to the welcome panel.
- Clicking it opens an **ephemeral changelog viewer**.
- The viewer includes a **version dropdown** to select which version’s notes to view.

## Per-version changelog files

The bot now supports loading changelog entries from individual files under:

- `changelog/<version>.md`

If the `changelog/` directory exists and contains `*.md` files, the bot will prefer those files over parsing `CHANGELOG.md`.

## Permission gating for Unreleased

- **Unreleased** entries are restricted to officers/admins.
- Non-officers see a message that they’re viewing public entries only.

## Versioning / release metadata

- Added repo-tracked `discord_bot/VERSION` for runtime version reporting.
- Updated release automation to bump version files consistently.
