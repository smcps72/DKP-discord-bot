## Raid improvements

- New "Not in raid" group (Group 0) — members placed here won't receive DKP awards.
- You can now pick a voice channel directly from the Sync Voice command instead of joining it first.
- Players who join voice after the first sync are automatically placed in the "Not in raid" group until moved.
- Button labels updated for clarity: "Update Team" is now "Sync Voice", and the old "Sync Voice" is now "Add Voice Channel".
- Cleaner DKP messages when adjusting a single member.

## Guild Bank refinements

- Deposit flow is now a single popup — no more extra menus before entering item details.
- Guild bank panel only shows Deposit and Withdraw buttons for a cleaner look.
- Inventory and transaction logs now show player names instead of blue mention links.
- Held-by field accepts a player name instead of requiring you to pick from a user list.
- Category field is now freeform — type any category you want instead of choosing from a fixed list.
